# FTB Banners

Lets you add simple, floating images in world with commands. This mod can be used in maps to display banners on events, e.g. completing all tasks in a quest-based map. Regular players can't use commands to change banners. Currently only way to edit banners is to use NBT editor (such as FTB Utilities' /nbtedit), but I'm working on that! Blocks become invisible and untouchable when you are not in creative mode.

Use https://github.com/FTBTeam/FTB-Mods-Issues for any mod issues
